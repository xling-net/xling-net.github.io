## 2. Description of Service

HTTPBuddy is an iOS HTTP/API and WebSocket debugging tool. It allows developers to compose and send HTTP requests, debug WebSocket connections, review history, measure phase timing, simulate concurrent load, export data in HAR or raw formats, and connect to Postman/Apifox for interface synchronization.
