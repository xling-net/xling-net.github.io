## Frequently Asked Questions

**Q: What platforms does HTTPBuddy support?**

HTTPBuddy is an iOS app built with SwiftUI.

**Q: Where is my request and session history stored?**

All request records and WebSocket session history are stored locally on your device using SwiftData. No data is synced to iCloud or uploaded to our servers.

**Q: What features are available in the free version?**

The free version includes the core HTTP Client and basic request sending. Pro features such as HAR export, request replay, concurrent load testing, expression injection, scripts, and WebSocket debugging are unlocked with a one-time Pro Lifetime purchase.

**Q: How do I connect Postman or Apifox?**

In the API tab, enter your own API Key and Workspace/Project ID. HTTPBuddy fetches your interface list from these third-party services using the credentials you provide. We never access or store these credentials on our servers.
